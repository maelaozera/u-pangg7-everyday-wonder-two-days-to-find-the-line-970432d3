A single sentence that makes a small everyday moment strange and new — written to `/output/entry.txt` by a small TypeScript program.

> My cracked phone screen caught the sunset and split it into two evenings, one for each thumb.

## Run it

```sh
node main.ts
```

This writes the single-line entry to `/output/entry.txt` (creating `/output` if needed). The program is deterministic: every run writes the exact same bytes.

## The gate

The gate requires `/output/entry.txt` to be UTF-8 text of 1–200 characters, not only whitespace, exactly one line. This entry is 93 characters, so it passes.
